Git-as-a-DB: Auth & Cookie Demo

Xác thực tài khoản GitHub & Ghi nhớ phiên bằng Cookie 30 ngày

Đang kiểm tra Cookie...

Đăng nhập để kết nối GitHub

Hệ thống sẽ lưu token vào Cookie trình duyệt (30 ngày). Lần sau bạn truy cập lại hoặc F5 sẽ tự động vào thẳng mà không cần đăng nhập lại.

Cách 1: Trải nghiệm 1-Click

Đăng nhập bằng GitHub OAuth

Được chuyển hướng đến trang cấp quyền chính thức của GitHub. Sau khi đồng ý, Cookie phiên sẽ tự động được gán.

Đăng nhập với GitHub

Yêu cầu cấu hình GITHUB_CLIENT_ID trong file .env

Cách 2: Test Ngay Không Cần Cấu Hình

Nhập Personal Access Token (PAT)

Dành cho bạn muốn test nhanh ngay lập tức. Token sẽ được xác thực với GitHub và lưu an toàn vào Cookie 30 ngày.

Chưa có token? Tạo nhanh 1 token (chọn quyền gist)
Cookie Đang Hoạt Động: Tự động nhận diện phiên từ trình duyệt
Tên Cookie: gh_token Thời hạn lưu: 30 ngày (Max-Age = 2592000s) Bảo mật: HttpOnly, SameSite=Lax
