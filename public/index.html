Đăng nhập để kết nối GitHub

Hệ thống sẽ lưu token vào Cookie trình duyệt (30 ngày). Lần sau bạn vào lại web sẽ tự động nhận diện mà không cần đăng nhập lại.

Cách 1: Trải nghiệm 1-Click

Đăng nhập bằng GitHub (OAuth)

Yêu cầu chạy local hoặc có server backend proxy để bảo mật Client Secret.

Trên GitHub Pages tĩnh, vui lòng dùng Cách 2 (PAT) bên phải.

Cách 2: Khuyên Dùng Trên GitHub Pages

Nhập Personal Access Token (PAT)

Token được xác thực trực tiếp và lưu vào Cookie 30 ngày trên máy của bạn (100% Zero-Backend).

Chưa có token? Tạo nhanh 1 token (chọn quyền gist)

Tên Cookie: gh_token Thời hạn lưu: 30 ngày (Max-Age = 2592000s) Lưu trữ: Browser Persistent Cookie + LocalStorage
