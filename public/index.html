Thuật toán Binary Search (Tìm Kiếm Nhị Phân)

Đăng bởi @thing-or-think • Python
Vừa xong

Thuật toán tìm kiếm nhị phân trên mảng đã sắp xếp với độ phức tạp thời gian cực nhanh O(log n).

def binary_search(arr, x):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == x: return mid
        elif arr[mid] < x: low = mid + 1
        else: high = mid - 1
    return -1

Cách sao chép sâu (deep copy) đối tượng JavaScript chuẩn hiện đại bằng native API structuredClone.

// Phương thức native có sẵn từ Node 17+ và trình duyệt hiện đại:
const original = { name: "Alice", details: { age: 25, skills: ["JS", "Git"] } };
const cloned = structuredClone(original);
cloned.details.age = 26;
console.log(original.details.age); // 25 (Không bị thay đổi!)

Thuật toán Kiểm Tra Số Nguyên Tố Tối Ưu

Đăng bởi @developer • C++
Hôm qua

Kiểm tra số nguyên tố bằng cách duyệt bước nhảy 6 (dạng 6k ± 1), độ phức tạp O(căn n / 3).

bool isPrime(int n) {
    if (n <= 1) return false;
    if (n <= 3) return true;
    if (n % 2 == 0 || n % 3 == 0) return false;
    for (int i = 5; i * i <= n; i += 6) {
        if (n % i == 0 || n % (i + 2) == 0) return false;
    }
    return true;
}
